# ReSpawn Stats

ReSpawn Stats is a personal tool of the YouTube channel Re:Spawn (@RespawnGamingFR). It reads the channel's own statistics (views, subscribers, retention), read-only, to display them in a private dashboard on the owner's computer.

## Privacy policy

ReSpawn Stats is used only by the channel owner. Data obtained through the YouTube API Services stays on the owner's personal computer; it is never sold, shared or transferred to third parties. No data from other users is collected.

Access can be revoked at any time at https://myaccount.google.com/permissions.

ReSpawn Stats uses YouTube API Services: see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
